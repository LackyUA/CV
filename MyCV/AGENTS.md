# Project Instructions

## Project documentation

Treat the documents in `Docs/` as project requirements.

Before you plan, modify, or review code:

1. Read `Docs/Index.md` completely.
2. Use its document catalog to identify all applicable documents.
3. Read each applicable document completely.
4. Follow its rules during implementation and review.
5. Before completion, verify the change against each applicable document.

If existing code conflicts with a document, follow the document. Report the
conflict instead of copying the existing pattern.
