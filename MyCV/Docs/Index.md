# Project Documentation

The documents in this directory define project requirements. Use the catalog
to identify the documents that apply to your task. If more than one topic
applies, read all applicable documents.

## Document catalog

- For technical writing in Markdown documentation, repository instructions,
  agent skills, or Swift documentation comments, read
  [`Docs/TechnicalWritingStyle.md`](TechnicalWritingStyle.md).
- For the CoreUI design-system hierarchy, component placement, or the
  foundations, atoms, molecules, organisms, and templates layers, read
  [`Docs/DesignSystemStructure.md`](DesignSystemStructure.md).
- For Swift declaration visibility, member ordering, `MARK` sections,
  private extensions, or constants, read
  [`Docs/DeclarationOrdering.md`](DeclarationOrdering.md).
- For screens in the Application package, view models, states, view
  configurations, or the division of data and rendering between a view model
  and a view, read [`Docs/ScreenArchitecture.md`](ScreenArchitecture.md).
- For haptics or sensory feedback, read
  [`Docs/SensoryFeedback.md`](SensoryFeedback.md).
- For stacked branches, cascade pull requests, rebases, or pull-request
  dependencies, read
  [`Docs/CascadePullRequests.md`](CascadePullRequests.md).

When you add a policy document to `Docs/`, add its topic and path to this
catalog.
