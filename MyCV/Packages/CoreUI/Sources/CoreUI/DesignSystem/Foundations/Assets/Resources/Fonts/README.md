# Fonts

Add the design system's display face here (SIL Open Font License, https://fonts.google.com/specimen/Orbitron):

- `Orbitron-Bold.ttf` (weight 700)
- `Orbitron-ExtraBold.ttf` (weight 800)

`UIFont.orbitron(ofSize:weight:)` registers them automatically; until they exist it falls back to SF Pro Expanded.
